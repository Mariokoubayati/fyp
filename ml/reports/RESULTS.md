Generated by `python -m unicircle_ml.train`. Do not edit by hand.

Model: **gradient_boosting** (`trust-hgb-1`), trained on 11827 synthetic loan requests (8.7% defaulted). Chosen on validation AUC: logistic_regression 0.711, gradient_boosting 0.7729.

Task: predict whether a loan request defaults, using only the borrower's history before it.

## Limitations

- All data is synthetic. We designed the generator, so these numbers show the method works on behaviors we modelled, not on real students.
- The shifted and unseen-type tests reduce, but do not remove, that circularity. A pilot with real loans would be the real test.
- A new kind of fraud is the weak spot: trained without strategic defaulters, the model ranks few of their cash-outs in the riskiest 20%. It still beats the rules on AUC there, but it does not discover a strategy it has never seen. Retraining as new patterns appear is part of the design.
- Most of the gain on rings comes from behavior the rules also look at (short loans, reciprocity, few partners). The model combines these signals; the rules can only cap them one by one.
- Requests are scored as if every one were allowed, so both methods are judged on the same requests. In the app, the rules also cap gradient boosting-approved amounts.
